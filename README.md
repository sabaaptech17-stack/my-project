# Umm-e-Saba — Personal Portfolio

A responsive personal portfolio website with a warm editorial aesthetic.

## Project files

- `index.html` — website structure, sections, text, and project descriptions.
- `style.css` — colour palette, typography, layout, decorative artwork, and responsive styling.
- `script.js` — mobile navigation and automatic footer year.
- `README.md` — project information and setup instructions.

## How to open the website

1. Download and extract the ZIP folder.
2. Keep all four files together in the same folder.
3. Open `index.html` in a web browser.

## Personal details to check

- The portfolio currently uses the name **Umm-e-Saba**.
- Replace `your.email@example.com` in `index.html` with the email address you want people to use.
- The project descriptions are based on the projects included in this portfolio. Update them if you want to show different work.
- Add links to live projects, GitHub, or social profiles when you are ready.

## Technologies used

HTML5 · CSS3 · JavaScript

## Design

Warm beige and cocoa-brown colours, terracotta accents, editorial serif headings, subtle paper grain, CSS-made artwork, project showcases, and a responsive mobile menu.

Google Fonts are loaded online. If there is no internet connection, the page uses fallback fonts.
